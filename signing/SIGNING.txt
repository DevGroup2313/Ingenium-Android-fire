The signing key
===============

Android installs an update over an existing app only when both are signed
with the same key. So every build of the Android and Fire app is signed with
one key, and a newer build installs over the older one and keeps your models
and your work.

Since 6.2 the key and its password live only in this repository's secrets,
never in its files. On github.com open Settings, Secrets and variables,
Actions, and add:

  ANDROID_KEYSTORE_B64       the key file (.p12 or .keystore), as base64
  ANDROID_KEYSTORE_PASSWORD  its password
  ANDROID_KEY_ALIAS          only if the key's name is not "app"

Ingenium's Fabrica makes a key on your own device and saves it as a .p12
file (Save this key). Keep the file and its password safe, away from the
computer: anyone holding both could sign an app that installs over yours.

The key that was kept in this folder (ingenium-release.keystore) has been
carried inside earlier Ingenium pages, which are public, so it is being
replaced. Until the new key is in the secrets, the build still uses the old
one and says so in its log. The change to the new key is made so that an
installed app updates without being removed first (a signing lineage,
security/key_rotation_*.sh in the Mac mini repository); after it, an app
signed with the old key alone no longer installs over yours.

The iPhone and iPad app is not signed here: Apple requires you to sign it
with your own Apple ID when you install it (see INSTALL_MOBILE.md).
